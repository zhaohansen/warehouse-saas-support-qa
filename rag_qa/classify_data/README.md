# 企业知识问答分类样本

`enterprise_scope_v2.jsonl` 是当前训练集，共 240 条，企业资料和通用知识各 120 条。每行字段：

- `query`：问题文本；
- `label`：`企业资料` 或 `通用知识`；
- `topic`：主题，用于分层；
- `family`：同一意图的改写族；
- `split`：`train` 或 `test`。

数据按 `family` 划分训练/测试（196/44），同一改写族不会同时出现在两边。测试集覆盖 6 个企业主题族和 5 个通用主题族，包含 `VPN 是什么？` / `我们公司的 VPN 怎么申请？`、`云帆科技的餐卡怎么充值？` 等易混问法。企业资料类指必须查本地资料才能确认的业务事实，资料未覆盖的问题也归入该类。数据不复用 `rag_qa/rag_assessment/warehouse_evaluate_data.json` 的评估题原文。

`enterprise_scope.json` 是旧的 160 条模板样本，保留用于对照，不再作为默认训练数据。示例数据均为虚构演示，实际使用前应人工核验并补充真实标注。
