# AI 学科知识手册

## 1. 机器学习的基本范式

机器学习的目标是从数据中学习一个映射函数，使它在没见过的样本上也能给出正确结果，这个能力称为泛化。标准流程包括：定义任务、收集与清洗数据、特征工程、选择模型、训练、评估、调参与上线监控。

按学习信号可分为监督学习（有标签）、无监督学习（无标签）、半监督学习（少量标签）、强化学习（通过奖励信号学习策略）。

模型能力的上限由数据和特征决定，算法只是逼近这个上限。因此实际项目中，数据质量与标注一致性往往比换模型更关键。

## 2. 监督学习与无监督学习

监督学习分为分类与回归。分类输出离散类别，常用逻辑回归、决策树、随机森林、梯度提升树、支持向量机、神经网络；回归输出连续值，常用线性回归、回归树、GBDT。

无监督学习包括聚类（K-Means、层次聚类、DBSCAN）、降维（PCA、t-SNE）、异常检测。聚类用于发现数据的自然分组，降维用于可视化与去噪。

自监督学习是近年主流：从无标注数据中构造代理任务（如预测被遮住的词、判断句子是否相邻），学到通用表示后再迁移到下游任务。大语言模型的预训练本质上就是自监督学习。

## 3. 过拟合与正则化

过拟合指模型在训练集表现好、在验证集表现差，本质是记住了训练数据的噪声而非规律。欠拟合则是模型容量不足，训练集和验证集都差。

判断方法是对比训练集与验证集的损失曲线：训练损失持续下降而验证损失回升，即为过拟合。

常见对策：增加数据或做数据增强、降低模型复杂度、早停、Dropout、L1/L2 正则化、批归一化、集成学习。L1 倾向于产生稀疏权重可用于特征选择，L2 让权重整体变小更平滑。

交叉验证（如 5 折）能在数据量有限时更可靠地估计泛化性能，避免单次划分带来的偶然性。

## 4. 神经网络与反向传播

神经网络由多层线性变换与非线性激活函数堆叠而成。没有激活函数时，多层线性变换等价于单层，无法拟合非线性关系。常用激活函数有 ReLU、GELU、Sigmoid、Tanh。

训练过程是：前向传播计算输出与损失，反向传播用链式法则计算每个参数对损失的梯度，优化器按梯度更新参数。常用优化器有 SGD、Momentum、Adam、AdamW。

学习率是最重要的超参数，过大会震荡不收敛，过小则收敛慢。常用策略包括预热、余弦退火、阶梯衰减。梯度消失与梯度爆炸可通过残差连接、归一化、梯度裁剪缓解。

## 5. Transformer 与自注意力

Transformer 完全基于注意力机制，抛弃了循环结构，因而可以并行计算，成为大模型的基础架构。核心组件包括多头自注意力、前馈网络、残差连接、层归一化、位置编码。

自注意力的计算是：每个 token 映射为 Query、Key、Value 三个向量，用 Query 与所有 Key 做点积得到相关性分数，除以维度的平方根防止数值过大，经 softmax 归一化后对 Value 加权求和。公式为 Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V。

多头注意力让模型在不同子空间关注不同关系，比如一个头关注语法依赖，另一个头关注指代关系。位置编码用于注入顺序信息，分为可学习的绝对位置编码与旋转位置编码 RoPE。

## 6. 预训练与微调

预训练是在大规模无标注语料上学习通用语言表示，目标通常是预测下一个 token（自回归）或还原被遮挡的 token（自编码）。预训练成本极高，但一次训练可服务多任务。

微调是在预训练模型基础上，用少量领域数据继续训练，使其适配具体任务。全参数微调需要较大显存，且每个任务存一份模型，成本高。

参数高效微调（PEFT）只训练少量额外参数：LoRA 冻结原权重，在旁路注入低秩矩阵，推理时可合并回原权重；Prefix Tuning 与 Prompt Tuning 在输入前拼接可训练向量；Adapter 在层间插入小模块。

## 7. 词向量与 Embedding

Embedding 把文本映射为稠密向量，语义相近的文本在向量空间中距离更近。早期用 Word2Vec、GloVe 得到静态词向量，无法处理一词多义；现在主流用预训练模型生成上下文相关的动态向量。

相似度常用余弦相似度、内积、欧氏距离。向量通常做归一化，使内积等价于余弦相似度。

检索场景要求文档与查询用同一个模型编码，否则向量空间不对齐，相似度没有意义。中文场景常用 BGE、M3E、text2vec 系列。BGE-M3 可以同时输出稠密向量与稀疏向量，支持多语言与长文本。

## 8. RAG（检索增强生成）

RAG 的思路是：先从外部知识库检索与问题相关的内容，再把内容作为上下文拼进提示词，让大模型基于这些内容作答。它解决了大模型知识滞后、缺乏私有知识、容易编造三个问题，且不需要重新训练模型。

完整链路包括：文档解析、文本切分、向量化、入库、查询改写、召回、重排、上下文拼接、生成、引用溯源。

切分策略直接影响效果。块太大，噪声多且占用上下文；块太小，语义不完整。常用父子块方案：子块用于精准检索，命中后回溯父块提供完整上下文。

召回阶段常做混合检索：稠密向量负责语义匹配，稀疏向量或 BM25 负责关键词精确匹配，两路结果加权融合。重排阶段用 CrossEncoder 对查询与候选逐对打分，比向量内积更准但更慢，因此只对少量候选使用。

## 9. 大模型幻觉与抑制

幻觉指模型生成看似合理但与事实不符的内容。成因包括训练数据中的噪声与错误、模型倾向于生成流畅文本、上下文不足时用先验知识补全、长尾知识覆盖不足。

抑制手段分为几类：检索增强，让回答有据可依；提示词约束，要求只依据给定资料作答、无法回答时明确说明；输出校验，用规则或第二个模型核查关键信息；引用标注，要求给出出处便于人工核验；温度调低，减少随机性。

工程上最重要的是设置"检索为空时的兜底"：当没有召回任何相关内容时，直接返回固定话术，而不是让模型自由发挥。同时应当给相似度设置阈值，过滤低分文档，避免把不相关内容塞进上下文。

## 10. 常见评估指标

分类任务用准确率、精确率、召回率、F1、AUC。精确率关注"判为正的里面有多少真的是正"，召回率关注"真正的正例有多少被找出来"，F1 是两者的调和平均。样本不均衡时准确率会失真，应看 F1 或 AUC。

生成任务用 BLEU、ROUGE、BERTScore 衡量与参考答案的相似度，但它们与人类判断相关性有限。

RAG 系统常用 RAGAS 框架，四个核心指标：忠实度衡量答案是否都能由上下文支撑，答案相关性衡量答案是否切题，上下文精确率衡量召回的上下文中相关内容的比例，上下文召回率衡量标准答案所需信息被召回的比例。

线上还应监控响应延迟、检索命中率、无答案率、用户追问率等业务指标。

## 11. 提示工程

提示词的基本结构包括角色设定、任务描述、约束条件、输入数据、输出格式、示例。结构化提示比一句话提问稳定得多。

常用技巧：少样本示例（Few-shot）让模型模仿格式；思维链（CoT）要求分步推理，提升复杂任务表现；让模型先给结论再给理由或反之，按场景选择；明确输出格式（JSON、Markdown 表格）便于程序解析。

约束要写"做什么"而不是只写"不要做什么"。要求模型在信息不足时输出固定话术，比要求它"不要编造"更有效。

提示词应当版本化管理，改动用同一批测试用例回归对比，避免凭感觉调优。

## 12. 参数高效微调 LoRA

LoRA 的核心假设是微调时的权重更新具有低秩特性。它冻结原模型参数，对每个目标层旁路两个小矩阵 A 与 B，其中 A 降维、B 升维，实际更新量为 BA，参数量远小于原矩阵。

训练时只更新 A 与 B，显存占用大幅下降，可以在消费级显卡上微调较大的模型。推理时可以把 BA 加回原权重 W，不增加推理延迟。

关键超参数是秩 r 与缩放系数 alpha，r 越大容量越强但参数量与过拟合风险上升。通常对注意力层的 Q、K、V、O 投影加 LoRA，效果与成本平衡较好。

LoRA 适合领域风格适配与任务对齐，不适合注入大量新知识，后者更适合用 RAG 解决。
