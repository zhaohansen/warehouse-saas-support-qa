【虚构演示资料】云帆科技新员工入职指南

说明：本文为虚构演示资料，仅用于企业知识库问答项目演示，不代表任何真实企业制度。文中的“云帆科技”及所有角色均为虚构。

一、入职第一天
1. 报到：入职当天 9:30 前到行政部门前台报到，出示身份证和录用通知。
2. 提交材料：身份证复印件、学历证明、银行卡信息和紧急联系人信息。
3. 领取物品：工牌、员工手册和基础办公用品。
4. 参加培训：上午由人力资源部门介绍公司情况和基本制度；下午由部门负责人介绍团队职责，并与导师见面。

二、领取办公设备
1. 申请：入职当天向行政部门提交办公设备申请，填写姓名、部门、入职日期和设备需求（笔记本电脑、显示器或外设）。
2. 审批与配置：行政专员核对申请后联系 IT 部门配置设备；IT 部门完成系统安装和资产登记。
3. 交付：IT 部门与员工当面确认设备编号和设备状态，员工在资产清单上签字。
4. 异常处理：设备缺货时，行政专员告知预计到货时间并提供临时设备；设备故障联系 IT 服务台。
5. 归还：员工离职或转岗时，按资产清单将设备归还行政部门，由行政部门与 IT 部门共同核销。

三、开通账号
1. 公司邮箱：由 IT 部门在入职当天创建，账号信息发送至员工提供的个人邮箱。
2. 协作平台：直属负责人在内部系统提交账号申请，IT 部门开通后发送激活邮件。超过 1 个工作日未收到激活邮件，联系 IT 服务台。
3. 内部系统权限：直属负责人根据岗位角色发起权限申请，IT 部门根据审批结果开通。
4. 查询进度：账号和权限申请进度可向直属负责人查询；登录故障联系 IT 服务台。

四、遇到问题找谁
1. 设备、账号、登录故障：联系 IT 服务台。
2. 入职材料、工牌、办公用品：联系行政部门。
3. 岗位职责、工作安排、权限申请：联系直属负责人。
4. 薪酬、社保、公积金：联系人力资源部门。
5. 报销和差旅：联系财务部门；制度问题可先咨询直属负责人。
6. 协作平台使用问题：先查看平台内“帮助与反馈”，仍未解决再联系 IT 服务台。

五、试用期安排
新员工试用期内的主要任务由直属负责人安排，导师负责日常指导和答疑。转正评估由直属负责人发起，人力资源部门审核。试用期内需要请假、报销或出差的，按公司制度和本指南中的流程办理。

六、入职一周内建议完成的事项
1. 完成公司邮箱和协作平台激活。
2. 确认内部系统权限与岗位职责一致。
3. 与导师确认第一个月的工作目标。
4. 核对资产清单中的设备编号和状态。
