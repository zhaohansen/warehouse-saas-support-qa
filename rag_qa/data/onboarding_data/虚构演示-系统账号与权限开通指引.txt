【虚构演示资料】云帆科技系统账号与权限开通指引

说明：本文为虚构演示资料，仅用于企业知识库问答项目演示，不代表任何真实企业制度。文中的“云帆科技”及所有角色均为虚构。

一、账号类型
新员工需要开通三类账号：公司邮箱、协作平台账号、内部系统账号（用于请假、差旅、报销和账号申请）。

二、开通顺序
1. 公司邮箱：IT 部门在入职当天创建，账号信息发送至员工提供的个人邮箱。
2. 协作平台：直属负责人在内部系统提交账号申请，IT 部门审核并创建账号，系统向公司邮箱发送激活邮件。
3. 内部系统权限：直属负责人按岗位角色发起权限申请，IT 部门根据审批结果开通。

三、责任人与时限
1. 公司邮箱：IT 部门负责，入职当天完成。
2. 协作平台：直属负责人提交申请，IT 部门在 1 个工作日内开通并发送激活邮件。
3. 内部系统权限：直属负责人发起，部门管理员审批，IT 部门开通。
4. 超过 1 个工作日未收到激活邮件：联系 IT 服务台核实邮箱地址并重新发送。

四、项目权限
项目成员由项目负责人添加，不需要 IT 部门开通账号。
系统角色（项目负责人、部门管理员、平台管理员）变更：直属负责人发起，部门管理员审批，IT 部门执行；平台管理员变更还需 IT 部门负责人确认。

五、新员工完整例子
新员工入职后依次办理：IT 部门创建公司邮箱 → 直属负责人提交协作平台账号申请 → 员工用公司邮箱激活账号 → 项目负责人把员工加入项目 → 需要部门管理员角色时，由直属负责人发起权限变更。
顺序不能颠倒：没有公司邮箱无法接收协作平台激活邮件；没有协作平台账号无法被加入项目。

六、异常处理
1. 激活邮件未收到：先检查垃圾邮件，再联系 IT 服务台。
2. 账号开通后 7 天内未激活被停用：由直属负责人重新提交申请。
3. 权限不足：向直属负责人说明岗位需要，按权限变更流程办理。
4. 登录故障：联系 IT 服务台，提供姓名、工号、部门和错误提示截图。

七、查询
账号和权限申请进度向直属负责人查询；开通结果和登录故障向 IT 服务台查询。
