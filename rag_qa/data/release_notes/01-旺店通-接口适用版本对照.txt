【正文】
一、整理说明
本文根据旺店通开放平台公开 API 文档中的“适用版本”字段整理，用于实施与售后初判时先确认客户版本是否支持目标接口。具体字段和限制仍以各接口原文为准。

二、接口与适用版本对照
1. trade_push.php（创建原始订单）：客户端 V2.4.5.0 及以上。
2. api_goods_stock_change_query.php（查询库存同步）：客户端 V2.4.5.0 及以上。
3. sales.StockSync.calcStock（计算自有平台货品应该同步的库存）：客户端 V1.3.3.1 及以上。
4. stockout_order_query_trade.php（查询销售出库单）：客户端 V2.4.6.6 及以上。
5. finance.settle.Logistics.search（电子面单号查询）：客户端 V1.5.2.0 及以上。
6. stock_query.php（查询库存成本、可用库存数据）：网页版。
7. stockin_order_push.php（其他入库单）：客户端 V2.4.8.4 及以上。
8. sales.TradeQuery.querySelfOrderWithDetail（自有平台及线下平台订单查询）：客户端 V1.6.0.8 及以上。
9. wms.StockSpec.search2（获取单品库存量）：客户端 V1.6.0.10 及以上，且需要仓库权限。
10. stock_query.php 的 is_sales_num 字段：20261027 版本及以上。

三、同一问题在不同版本下的处理差异
1. 库存同步 API：客户端 V2.4.5.0 及以上才能使用查询库存同步接口；低于该版本时，不能按新接口方案排查，应先升级或改用网页版/其他可用接口。
2. 销售出库单查询 API：客户端 V2.4.6.6 及以上才支持；V2.4.5.x 及以下调用会表现为接口不存在或版本不匹配。
3. 网页版库存查询：使用 stock_query.php，与客户端的 api_goods_stock_change_query.php 不是同一个接口；返回字段包含库存量、可用库存、锁定量、采购在途量、调拨在途量等，适合核对库存差异构成。
4. 销量字段：网页版 stock_query.php 的 is_sales_num 仅在 20261027 版本及以上可用，低版本传该字段不会返回销量信息。

四、使用建议
接到“接口调不通”“字段没有返回”的问题时，先问客户产品形态（客户端/网页版）和具体版本，再对照本表。不要用高版本接口文档直接指导低版本客户操作。
