【虚构演示资料】云帆科技协作平台角色与权限说明

说明：本文为虚构演示资料，仅用于企业知识库问答项目演示，不代表任何真实企业产品或服务。文中的“云帆科技”及所有角色均为虚构。

一、系统角色定义
1. 普通成员：创建任务、编辑本人创建的文档、查看所在项目内容。
2. 项目负责人：管理项目成员、分配任务、调整任务状态、关闭项目。
3. 部门管理员：管理部门空间、查看部门成员、调整部门内成员角色。
4. 平台管理员：由 IT 部门指定，负责平台配置和全局权限。

二、项目成员与项目权限
1. 加入项目：由项目负责人把员工添加为项目成员，添加后即可查看项目任务和文档。
2. 移出项目：由项目负责人移除；员工离职或转岗时，由部门管理员核对并回收项目权限。
3. 项目内分工：项目负责人可以指定任务负责人，但这不改变员工的系统角色。
4. 例：新员工激活协作平台账号后仍看不到项目，由项目负责人将其加入项目即可，不需要 IT 部门重新开通账号。

三、系统角色变更
1. 发起人：直属负责人。
2. 审批人：部门管理员。
3. 执行方：IT 部门。
4. 平台管理员变更：除部门管理员审批外，还需 IT 部门负责人确认。
5. 变更完成后，IT 部门通知申请人和部门管理员。

四、转岗与离职
1. 转岗：部门管理员回收原部门的项目权限，直属负责人按新岗位重新发起权限申请。
2. 离职：部门管理员回收项目权限，IT 部门停用账号，行政部门与 IT 部门共同核销设备。

五、容易混淆的场景
1. 账号已开通但无法登录：属于登录问题，联系 IT 服务台。
2. 能登录但看不到某个项目：不是登录故障，找项目负责人添加项目成员。
3. 能看到项目但无法调整成员：需要项目负责人权限，走系统角色变更审批。
4. 需要部门管理员角色：由直属负责人发起，部门管理员审批，IT 部门执行。

六、查询
项目成员和项目内权限向项目负责人查询；系统角色审批进度向部门管理员或 IT 部门查询。
